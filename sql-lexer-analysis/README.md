# Simple SQL Parser using Flex & Bison

This project demonstrates how to build a **lexer** (tokenizer) and **parser** for a simplified subset of SQL statements using **Flex** and **Bison**.

It supports basic `SELECT` statements like:

```sql
SELECT name, age, marks FROM students WHERE id=2;
```
The parser extracts and displays the columns, table name, and WHERE condition from the SQL query.

| File         | Description                                                                                                                                     |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `lexer.l`    | The **lexer definition** (Flex file). It breaks the input SQL query into tokens such as `SELECT`, `FROM`, `WHERE`, `IDENTIFIER`, `NUMBER`, etc. |
| `parser.y`   | The **parser definition** (Bison file). It defines grammar rules and actions to recognize SQL syntax and extract data.                          |
| `sql_parser` | The final compiled executable (created after building).                                                                                         |

# File Explanation

# lexer.l
This file defines how the input string is tokenized.


```sql
"SELECT"        { return SELECT; }
"FROM"          { return FROM; }
"WHERE"         { return WHERE; }
[a-zA-Z_][a-zA-Z0-9_]*   { yylval.str = strdup(yytext); return IDENTIFIER; }
[0-9]+          { yylval.num = atoi(yytext); return NUMBER; }
[ \t\r\n]+      { /* ignore whitespace */ }
.               { printf("Unknown character: %s\n", yytext); }
```

- Converts SQL keywords and identifiers into tokens for the parser.
- Ignores spaces and tabs.
- Uses yylval to pass token values (like strings or numbers) to the parser.

# parser.y
This file defines the SQL grammar and what to do when a valid statement is recognized.

Example grammar:
```sql
statement:
    SELECT column_list FROM table_name WHERE condition SEMICOLON
    {
        printf("\nParsed Successfully!\n");
        printf("Columns: %s\n", $2);
        printf("Table: %s\n", $4);
        printf("Condition: %s\n\n", $6);
    };
```

- Describes how valid SQL statements are structured.
- Uses Bison rules to match parts of the SQL command.
- Builds strings for columns, table, and conditions.
- $1, $2, $3, etc., refer to parts of the matched rule.
- $$ represents the final value of a rule.

# Build Steps
1 Generate the lexer
```sql
flex lexer.l
```
- This creates:
lex.yy.c  <- C file for the lexer

2 Generate the parser
```sql
bison -d parser.y
```
- This creates:
parser.tab.c   <- C file for the parser logic
parser.tab.h   <- Header file for tokens (used by lexer)

3 Compile both together
```sql
gcc parser.tab.c lex.yy.c -o sql_parser
```

4️4 Run the parser
```sql
./sql_parser
```
